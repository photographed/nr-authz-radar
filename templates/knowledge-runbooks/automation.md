# ランブック: 画面を経由しない API 呼び出し（D12）

## 意味
分散トレーシングの親（Browser / Mobile）が無い呼び出しの割合が、平常時より増えた。アプリを解析して API を直接呼ぶスクリプトや、
自動化された操作の可能性（JPCERT-AT-2026-0030 の「アプリを解析して API を特定する」手口）。**AI エージェントと断定しない。**

## 最初の15分
1. どの API で増えたか（U03 の平常時と比べる）。
2. その API は本来、画面・モバイル・外部連携のどれから呼ばれるものか（U02、コード監査）。
3. 同じ時間帯に D03（列挙）・D13（一定間隔）・D11（多数のネットワーク）が無いか。

## 判断
| 状況 | 見立て |
|---|---|
| 画面専用の API で、親の無い呼び出しが急増 | 直接呼び出し。データの取得（scraping）を疑う |
| 外部連携向けの API | 通常の利用の可能性。連携先の変更を確認 |
| デプロイ直後から | Browser の設定変更で分散トレーシングが外れた可能性 |

## 封じ込め（承認が必要）
- WAF / CDN の bot 対策、API のレート制限

## 再発防止
- 画面専用の API には、画面からの呼び出しであることを確かめる仕組みを検討する。データを返す API は所有者照合（S2）を必ず入れる
