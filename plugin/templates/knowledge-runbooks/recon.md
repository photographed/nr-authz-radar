# ランブック: 探索・偵察（D04）

## 意味
403 / 404 の割合が平常時より大きく増えた。存在しないパスや権限の無い API への試行（脆弱性スキャン、ID 列挙、旧 API の探索）の可能性。

## 最初の15分
1. どの API（トランザクション名）で増えたか（U05 と比べる）。
2. 少数のユーザーに偏っているか（D02・D03）。
3. 呼び出し元の内訳（U03）。画面を経由しない呼び出しが増えていれば自動化の可能性（D12）。
4. 直前のデプロイ（D18）。デプロイで URL が変わっただけ、ということがある。

## 判断
| 状況 | 見立て |
|---|---|
| 多数のパスに分散した 404 | 脆弱性スキャン・探索 |
| 特定の API の 403 が急増 | 権限の無い操作の試行（D05 も確認） |
| デプロイ直後から全体で増加 | 自分たちの変更（リンク切れ・設定ミス） |

## 封じ込め（承認が必要）
- WAF でのレート制限・遮断
- 旧 API（ゾンビ API）の無効化（U01 で利用状況を確認してから）

## 誤検知
- クローラ、監視ツール、フロントエンドの不具合

## 再発防止
- 使われていない API を削除する（コード監査の `dormant_critical`）
