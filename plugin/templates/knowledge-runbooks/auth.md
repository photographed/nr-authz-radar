# ランブック: 認証攻撃（D10・D11）

## 意味
- **D10**: 401 が平常時より大きく増えた。パスワードの総当たり、漏えいした認証情報の使い回し（credential stuffing）の可能性。
- **D11**: 1つのアカウントが、短時間に多数のネットワーク（ASN）・国から使われた。乗っ取られたアカウント、または分散した自動化。

## 最初の15分
1. どの API（ログイン・トークン発行）で増えたか。
2. 少数のアカウントに集中しているか、多数のアカウントに薄く広がっているか（後者は credential stuffing の典型）。
3. 成功したログイン（200）が混ざっていないか。**成功していれば乗っ取りの可能性**。
4. WAF / CDN の判定（`edge.verdict`）やエッジのログを確認する。

## 封じ込め（承認が必要）
- 対象アカウントのロック・パスワードリセット・トークン失効
- ログイン API のレート制限、bot 対策（チャレンジ）の強化

## ④ 調査へ
乗っ取りの可能性があるアカウントについて、ログイン成功後に何をしたかを I01〜I04 で調べる。

## 誤検知
- 社内の負荷試験、監視、パスワード変更の周知直後

## 再発防止
- MFA、ログイン試行の制限。IP 粒度の分析はエッジ側で行う（`shared/privacy.md`）
